# 🚀 Supabase + Vercel 部署指南

## 概述

本指南将帮助你把 RCA6.0 ERP 从 Mock 数据模式升级为使用 Supabase 真实数据库，并部署到 Vercel。

---

## 第1步：执行建表 SQL（5分钟）

1. 打开你的 Supabase 项目：`https://supabase.com/dashboard/project/odmshppyeeaqgurztpfy`
2. 左侧菜单点击 **SQL Editor**
3. 点击 **New query**
4. 打开项目中的 `sql/001_init_supabase.sql` 文件，全选复制
5. 粘贴到 SQL Editor 中
6. 点击 **Run**（或按 Ctrl+Enter）
7. 等待执行完成，应该看到 "Success. No rows returned."
8. 左侧菜单点击 **Table Editor**，应该能看到 25+ 张表

---

## 第2步：获取完整的 API 密钥（3分钟）

1. 在 Supabase Dashboard 左下角点击 **Settings**（齿轮图标）
2. 点击 **API**
3. 你需要复制以下 3 个值：

### Project URL
```
https://odmshppyeeaqgurztpfy.supabase.co
```
（这个已经知道了）

### Publishable Key（原 anon key）
- 在 "Publishable key" 部分，点击 **default** 行的复制按钮
- 完整格式：`sb_publishable_xxxxxxxxxxxxxxxxxxxxxx`
- ⚠️ 截图里看到的是截断的，你需要点击复制按钮获取完整值

### Secret Key（原 service_role key）
- 在 "Secret key" 部分（可能需要点击展开）
- 点击 **default** 行的复制按钮
- 完整格式：`sb_secret_xxxxxxxxxxxxxxxxxxxxxx`
- ⚠️ 这个密钥保密！不要发给任何人，不要提交到 GitHub

---

## 第3步：配置本地环境变量（2分钟）

1. 打开项目根目录的 `.env.local` 文件
2. 替换为真实值：

```bash
NEXT_PUBLIC_SUPABASE_URL=https://odmshppyeeaqgurztpfy.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=sb_publishable_你的完整publishable_key
SUPABASE_SERVICE_ROLE_KEY=sb_secret_你的完整secret_key
```

3. 保存文件
4. 重启开发服务器：`bun run dev`

---

## 第4步：验证数据库连接（3分钟）

1. 访问 http://localhost:3000/login
2. 用任意邮箱密码登录（暂时还是 Mock 登录）
3. 访问客户管理页面
4. 如果看到从 Supabase 加载的 5 条客户数据（CU001-CU005），说明连接成功！

> **注意**：目前只有客户管理模块已改造为 Supabase，其他模块仍使用 Mock 数据。
> 后续可以逐步迁移其他模块。

---

## 第5步：推送到 GitHub（5分钟）

```bash
# 初始化 git 仓库（如果还没有）
cd /home/z/my-project
git init
git add .
git commit -m "feat: Supabase integration"

# 创建 GitHub 仓库后，执行：
git remote add origin https://github.com/你的用户名/rca-erp.git
git branch -M main
git push -u origin main
```

⚠️ **重要**：确保 `.gitignore` 包含 `.env.local`（默认已包含），不要把密钥推到 GitHub！

---

## 第6步：部署到 Vercel（5分钟）

1. 打开 https://vercel.com，用 GitHub 登录
2. 点击 **Add New Project**
3. 选择 `rca-erp` 仓库，点击 **Import**
4. 在配置页面：
   - Framework Preset: Next.js（自动检测）
   - Build Command: `bun run build`（默认即可）
   - Output Directory: `.next`（默认即可）
5. **关键步骤**：展开 **Environment Variables**，添加以下 3 个变量：

| Name | Value |
|------|-------|
| `NEXT_PUBLIC_SUPABASE_URL` | `https://odmshppyeeaqgurztpfy.supabase.co` |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | `sb_publishable_你的完整publishable_key` |
| `SUPABASE_SERVICE_ROLE_KEY` | `sb_secret_你的完整secret_key` |

6. 点击 **Deploy**
7. 等待 2-3 分钟构建完成
8. 得到访问地址：`https://rca-erp-xxx.vercel.app`

---

## 第7步：绑定自定义域名（可选）

1. 在 Vercel 项目设置 → **Domains**
2. 添加你的域名（如 `erp.yourcompany.com`）
3. 在域名注册商处添加 CNAME 记录：
   ```
   CNAME erp → cname.vercel-dns.com
   ```
4. 等待 DNS 生效（通常几分钟到几小时）
5. Vercel 自动配置 HTTPS 证书

---

## 后续：迁移其他模块

目前只有客户管理已对接 Supabase。其他模块的迁移方法：

1. 在 `src/lib/api/` 下创建对应模块的 API 文件（参照 `customers.ts`）
2. 修改页面组件，用 `useQuery` + API 函数替换 `useStore()`
3. 用 `useMutation` 替换 `useStore.setState()`

可以让我帮你逐个模块迁移，每次迁移一个模块并验证。

## 常见问题

### Q: 执行 SQL 报错怎么办？
A: 把错误信息发给我，我帮你修复 SQL。

### Q: 页面显示 "Failed to fetch" 怎么办？
A: 检查 `.env.local` 中的 URL 和密钥是否正确，重启开发服务器。

### Q: Vercel 部署后页面白屏？
A: 检查 Vercel 的环境变量是否全部配置，查看 Vercel 的构建日志。

### Q: 数据不显示？
A: 在 Supabase Dashboard → Table Editor 检查表中是否有数据。
   如果没有，重新执行 SQL 的种子数据部分。

### Q: 如何重置数据库？
A: 在 Supabase SQL Editor 执行：
```sql
-- 删除所有表（谨慎！）
DROP SCHEMA public CASCADE;
CREATE SCHEMA public;
-- 然后重新执行 001_init_supabase.sql
```
