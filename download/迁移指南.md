## 迁移步骤

### 方案A：用 Cursor / Trae / Claude Code 打开

1. 下载 rca-erp-full.zip
2. 解压到电脑上
3. 用 Cursor / Trae 打开文件夹
4. 在项目根目录创建 .env.local 文件，填入环境变量
5. 运行 `bun install` 安装依赖
6. 运行 `bun run dev` 启动开发服务器
7. AI助手会自动读取 CLAUDE.md 理解项目

### 方案B：克隆GitHub仓库

```bash
git clone https://github.com/aazr8849-ship-it/rca-erp.git
cd rca-erp
bun install
# 创建 .env.local 填入环境变量
bun run dev
```

### 方案C：用 Claude Code / Codex CLI

```bash
# 安装 Claude Code
npm install -g @anthropic-ai/claude-code

# 在项目目录运行
cd rca-erp
claude

# Claude 会自动读取 CLAUDE.md 理解项目
# 然后你可以直接对话：
# "添加一个库存预警功能"
# "修改客户管理表单增加一个字段"
```
